# FlowVQ

## Example: FlowVQ for MNIST

1. Open `mnist_example.ipynb` in Colab
   [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/friolero/FlowVQ/blob/main/mnist_example.ipynb),
   or locally: `pip install -r requirements.txt jupyter && jupyter notebook mnist_example.ipynb`.
2. Select a GPU runtime.
3. Run all cells: trains FlowVQ and a VQ-VAE baseline, and plots the codebooks and the comparison.
